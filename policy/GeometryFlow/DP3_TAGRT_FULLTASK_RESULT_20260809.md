# TAGRT-DP3 full-task evidence audit (2026-08-09)

## Frozen research question

Can camera-derived, task-aligned object geometry improve a learned 3D
manipulation policy without a planner, simulator pose, stage label, or
nominal-plus-residual controller?

The tested DP3 policy consumes current/target object point clouds, 20-D
bimanual EEF proprioception, a 256-by-4 local functional-relation token, and a
9-D global remaining-SE(3) token.  It predicts six-step Cartesian action
chunks.  The NDF frame estimator and its confidence gate are frozen.

## Offline result that is established

The strict split trains on shoe IDs 2/3/4/7/8/9, validates on 1/6, and tests on
blind IDs 0/5.  The earlier full-task three-seed experiment showed that correct
TAGRT beat a separately trained neutral model on all four metrics for all three
seeds: 3.82% raw-action MAE, 5.50% active-arm MAE, 6.91% endpoint translation,
and 12.21% endpoint rotation.

The original row-wise dataset repeated the current observation three times.
That did not match online deployment, which supplied three real consecutive
observations.  After replacing repetition with causal episode-local history,
seed 0 produced:

| condition | raw action MAE | active-arm MAE | endpoint translation | endpoint rotation |
|---|---:|---:|---:|---:|
| correct TAGRT | 0.004325 | 0.006667 | 1.394 cm | 4.519 deg |
| zero geometry | 0.005124 | 0.007922 | 1.738 cm | 5.301 deg |
| episode-level shuffled | 0.005086 | 0.007434 | 1.608 cm | 5.766 deg |

Correct geometry remains better in all four metrics and in both pre-grasp and
post-grasp subsets.  Thus the mainstream-backbone compatibility and offline
causal-dependence claims remain supported.

## Learned hybrid gripper correction

Treating binary gripper commands as ordinary continuous diffusion dimensions
collapsed to the majority open command online.  A 76.6K-parameter binary
action head was therefore trained from the same geometry-conditioned DP3
context.  This is an action decoder, not a stage predictor.  Cartesian motion
remains generated by DP3 diffusion.

On blind IDs 0/5, the head reached 94.31% active-gripper accuracy, 98.90%
closed-command recall, and 90.03% closed-command precision.  The frozen
Cartesian base retained 1.402 cm / 4.520 deg endpoint error.

## Online evidence and failure boundary

All runs below use the same accepted simulator seed 100000 and are diagnostic
single episodes, not success-rate estimates.

| deployment | result | diagnostic |
|---|---:|---|
| old repeated-history model, one action/replan | 0/1 | online chain ran; mean geometry confidence 0.427 |
| causal-history model, one action/replan | 0/1 | no gripper close; best translation 12.97 cm, rotation 94.07 deg |
| hybrid gripper, one action/replan | 0/1 | trajectory never entered the learned closing region |
| hybrid gripper, standard six-action chunk | 0/1 | chunk semantics fixed; still no close on the unseen start state |
| expert grasp then hybrid placement | 0/1 | geometry valid fraction 0%; NDF ensemble disagreement 173.15 deg |

The six-action deployment cumulatively decodes every delta against the actually
reached EEF pose.  It removes the earlier stochastic one-step replanning
dither, but does not by itself solve the task.

The full-task result is therefore **not closed online**.  It must not be
reported as a successful end-to-end policy result.  The current evidence says:

1. DP3 learns and causally uses the two-level geometry representation offline.
2. The blind full-task archive is too small for arbitrary initial-pose
   closed-loop grasp generalization (shoe 0 has only two held-out trajectories).
3. More importantly for the paper claim, the frozen NDF ensemble loses
   agreement on grasped, camera-occluded shoe clouds, so its confidence gate
   removes geometry exactly when placement needs it.

## Next experiment gate

Do not expand seeds yet.  Keep the geometry-enhanced learned-policy main line
and fix the representation/deployment gap in this order:

1. build a grasped-object partial-view benchmark from the live simulator camera;
2. retrain or adapt the shoe NDF functional-frame estimator with realistic
   occlusion, point dropout, and gripper-occlusion augmentation;
3. require at least 80% valid-frame coverage and bounded temporal frame jumps on
   held-out grasped trajectories before policy rollout;
4. run matched correct-TAGRT versus neutral-DP3 closed-loop post-grasp placement
   on fixed seeds;
5. only after that passes, collect broader full-task initial-pose data and test
   observe-grasp-transport-place-release end to end.

This remains a learned geometry-conditioned manipulation route.  None of these
steps adds a planner, stage label, privileged simulator pose, or residual
controller.

Resource policy: default to one GPU.  Use a second GPU only when a measured
single-card memory or throughput bottleneck justifies it.
