\begin{abstract}
Point-cloud policies for robotic manipulation must operate on RGB-D observations whose samples vary with viewpoint, occlusion, depth noise, segmentation, and sensor configuration. Although semantic enrichment can reveal functional object parts, features attached directly to observed points remain coupled to these observation-specific samples, resulting in unstable policy inputs. We propose a stable object-centric semantic field that uses an observed object point cloud as support and reads part-aware embeddings at resampled 3D query locations. While the query locations are drawn from the observed object region, their semantics are inferred from the support-conditioned continuous field rather than attached to individual support samples. The field is trained from category-level part annotations using part anchoring, cross-instance alignment, and support-perturbation consistency, and is then frozen to export semantic point clouds as additional conditioning for a point-cloud policy. Experiments on four RoboTwin simulation tasks and four real-world bimanual manipulation tasks show that our representation provides more consistent functional-part features and improves policy success over raw point clouds, 2D feature lifting, and discrete 3D point-wise features, with larger margins over these baselines in the real-world evaluation. These findings highlight the value of organizing policy inputs around functional object structure, suggesting that object-conditioned semantic fields can help policies learn manipulation behaviors that transfer across object instances despite variability in their observations.

\end{abstract}
